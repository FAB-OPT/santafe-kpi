## การใช้งาน

**ดู KPI** — หน้าเปิดมาที่เดือนปัจจุบันเสมอ เลื่อนดูทั้งหน้า หรือกดเมนูซ้ายเพื่อกระโดดไปหัวข้อ

**ค้นหาหัวข้อ** ช่องค้นหาบนแถบบน พิมพ์ชื่อหัวข้อแล้วกด Enter จะพาไปหัวข้อนั้นทันที ข้ามหมวดให้เอง

**กรอบเนื้อหา** ทุกกราฟ ตาราง และรายการอยู่ในกรอบการ์ดของตัวเอง มีหัวเรื่องกำกับ ตัวจัดกรอบทำงานอัตโนมัติหลังสร้างหน้า จึงใช้ได้กับทุกหัวข้อโดยไม่ต้องแก้ทีละหัวข้อ

**ตารางยาว** แสดง 12 แถวแรกก่อน กดปุ่มใต้ตารางเพื่อดูทั้งหมด คอลัมน์ชื่อสาขาตรึงไว้ตอนเลื่อนตารางแนวนอน

**เมนู 5 หมวด** ยอดขาย · COL / COS · P&L · CEM · OSS เลือกหมวดจากปุ่มบนเมนูซ้าย (บนมือถือใช้แถบล่างจอ) หรือกด "ทุกหัวข้อ" เพื่อดูรวมทุกหมวดในหน้าเดียว แต่ละหมวดจะแสดงเฉพาะหัวข้อของหมวดนั้น หมวดที่เลือกไว้จะจำไว้ให้ครั้งหน้า โหมดพรีเซนต์ยังไล่ครบทุกหัวข้อเหมือนเดิม

**ตัวกรองด้านบน** — ช่วงเวลา (รายเดือน / ไตรมาส / ช่วงเดือน / ตั้งแต่ต้นปี) และ **โซนผู้จัดการเขต (BZM)** ใช้กับทุกหัวข้อที่มีข้อมูลรายสาขา

**เจาะดูรายละเอียดในหัวข้อ**

| หัวข้อ | ทำอะไรได้ |
|---|---|
| ยอดขายรายเดือน | 2 แท็บ: ยอดขาย/แผน/ปีก่อน และ รายได้ & กำไร (กำไรขั้นต้น · OP · กำไรสุทธิ จากงบกำไรขาดทุน) |
| %SSSG | เลือกสาขาจาก dropdown หรือคลิกแท่งเดือนในกราฟ → เห็น SSSG รายสาขาของเดือนนั้น แล้วคลิกชื่อสาขาต่อได้ |
| Delivery | การ์ด รวม · สัดส่วน · Grab · Line Man · Shopee · กราฟรายเดือน (3 แท่ง/เดือน) ติ๊กเทียบเดือนก่อน / ปีก่อนเดือนเดียวกัน |
| Trans·Ticket·ลูกค้า | ปุ่มช่องทาง (รวม / Dine In / Take away / Delivery) หรือคลิกแท่ง · ตารางรายเดือนพร้อมค่าเฉลี่ย |
| อันดับยอดขายสาขา | Top/Bottom ตามยอดขายหรือ %SSSG · จุดบอกว่าติดอันดับกี่เดือนติด · คลิกไปดู SSSG ของสาขานั้น |
| สุขภาพกลุ่มห้าง | จัดสาขาตามเจ้าของห้าง (Central, Lotus, Big C, The Mall, AWC, LH, Robinson, Seacon, แหลมทอง) เรียงจากแย่สุด คลิกดูสาขาในกลุ่ม |
| แนวโน้มรายโซน | กราฟเส้น 7 โซน BZM · คลิกโซนดูสาขา หรือกดกรองทั้งหน้าเป็นโซนนั้น |
| COL / COS | %ต้นทุนอาหาร %ค่าแรง และ Prime cost รายเดือน เทียบเดือนก่อนและปีก่อน พร้อมตารางรายสาขาเทียบค่าเฉลี่ยบริษัท |
| P&L | ผังบัญชีเต็ม พับ/กางหมวดย่อย · กำไรทุกชั้นถึงบรรทัดสุดท้าย · เลือกสาขา · เรียงมาก→น้อย · ติ๊กเทียบเดือนก่อน / ปีก่อน · ตารางสาขา × เดือน (%กำไร / %ต้นทุน / ค่าแรง) คลิกสาขาเพื่อดูงบเต็ม |
| CEM / OSS | กราฟ 3 กลุ่ม (ดีเยี่ยม / ปานกลาง / ต้องปรับปรุง) คลิกแท่งเห็นรายชื่อสาขา · ติ๊กเทียบเดือนก่อน / ปีก่อน · คะแนนรายหมวดเรียงมาก→น้อย คลิกหมวด/ข้อที่ตก เห็นว่าสาขาไหนตก |

**พรีเซนต์** — กดปุ่ม ▶ โหมดพรีเซนต์ (หรือกดปุ่ม P)

| ปุ่ม | ทำงาน |
|---|---|
| → / ↓ / Space | หน้าถัดไป |
| ← / ↑ | หน้าก่อน |
| Esc | ออกจากโหมดพรีเซนต์ |
| แตะขวา/ซ้ายของจอ (มือถือ) | ถัดไป / ก่อนหน้า |

## นำเข้าข้อมูลเดือนใหม่

เว็บรับไฟล์ 6 แบบ ลากวางในหน้า **⤒ นำเข้าข้อมูล** ได้เลย

### แบบ A — ไฟล์ Daily Sale (ไฟล์ปฏิบัติการรายเดือน `.xlsb` / `.xlsx`)

ลากไฟล์ `_Daily Sale <เดือน> <ปี>` เข้ามาตรงๆ ระบบอ่านเองจากชีตเหล่านี้ (ยึดคอลัมน์ **STF KT**)

| อ่านจากชีต | ได้หัวข้อ |
|---|---|
| `Daily Sales YTD` | ยอดขายรายเดือนทุกเดือน + ปีก่อน + MoM (รวมจากยอดรายวัน) |
| `Data Sales Daily` | ยอดเดือนของไฟล์ · ยอดปีก่อน · SSSG · จำนวนสาขา (ปีนี้ / ปีก่อน / same store) |
| `Daily Sale Delivery` | Delivery แยก Grab / Line Man / Shopee / Robinhood / Food Panda + สัดส่วนต่อยอดรวม |
| `Area7Dept` | Trans · Ticket · ลูกค้า และสาขาที่ดี/น่าเป็นห่วง (เทียบเดือนเดียวกันปีก่อน) |

**สิ่งที่ไฟล์นี้ไม่มี** — Budget, CEM/OSS, สาขาที่ Delivery ลดลงรายสาขา, จำนวนบิลแยกช่องทาง ให้เติมด้วยแบบ B

**ข้อควรรู้** — คอลัมน์ในไฟล์เป็นการเทียบ "ช่วงวันเท่ากัน" (เช่น 1–30 ส.ค. 26 เทียบ 1–30 ก.ค. 26) เว็บจะกำกับไว้ในการ์ด MoM · และเดือนล่าสุดมักยังไม่มีข้อมูลในชีตรายวัน (Delivery/แยกช่องทางจึงยังว่างจนกว่าไฟล์จะอัปเดต)

### แบบ B — แบบฟอร์มส่งยอดขาย (`แบบฟอร์มส่งยอดขาย 2026.xlsx`)

ลากเข้ามาตรงๆ ระบบอ่านชีตรายเดือน (`มกราคม 69` … ) เฉพาะสาขา Santa Fe รหัส 50xx

| ได้อะไร | หมายเหตุ |
|---|---|
| ยอดขาย + Budget (Plan Sale) รายเดือน | ใช้คอลัมน์ "Actual Sale สิ้นวัน" · Budget เดิมที่มีอยู่แล้วจะไม่ถูกทับ (แจ้งให้ดูว่าต่างกันเท่าไร) |
| Delivery แยก Grab / Line Man / Shopee + สัดส่วน | รวมจากรายสาขา |
| **สาขาที่ Delivery ลดมากสุด** (รวม + Line Man) | เรียงตามมูลค่าที่หายไป |
| Trans · Ticket · ลูกค้า + แยกช่องทาง Dine In / Take away / Delivery | จำนวนบิลและเช็คเฉลี่ยจริงรายช่องทาง |
| สาขาดี / น่าเป็นห่วง | เทียบเดือนก่อนหน้า |

เดือนที่ยังเก็บข้อมูลไม่ครบ (ยอดจริงต่ำกว่า 55% ของแผน) จะถูกข้ามอัตโนมัติ

### แบบ C — งบกำไรขาดทุน (`PL <เดือน>.xlsx`)

อ่านชีต `Dashboard P_L` บล็อก Santa Fe → เพิ่มหัวข้อ **กำไร-ต้นทุน (P&L)** รายได้ · Food % · Labor % · ค่าเช่า+สาธารณูปโภค · รวมค่าใช้จ่าย · กำไรก่อนโบนัส และ %กำไร ทุกเดือน

### แบบ D — ไฟล์ CEM (`cem.xlsx`)

ไฟล์ผลสำรวจลูกค้า (ชีต `Survey Questions and Answers`) — อ่านคอลัมน์ `คะแนนรวม` รายสาขา และดูเดือนจาก `Survey Name` (เช่น `2026_08`) แล้วสรุปเป็น เฉลี่ย · การกระจายคะแนน (ดีเยี่ยม 100% / ปานกลาง 92–99% / ต้องปรับปรุง < 92%) · Top 5

### แบบ E — ไฟล์ OSS (`oss.xlsx`)

ใบตรวจมาตรฐาน **1 สาขาต่อ 1 ไฟล์** — อ่านชีต `Summary`: รหัส/ชื่อสาขา, วันที่ (แปลง พ.ศ. → ค.ศ.) และ `% Achieved`

ลากไฟล์สาขาอื่นมาเพิ่มได้เรื่อยๆ ระบบสะสมคะแนนรายสาขาไว้แล้วคำนวณค่าเฉลี่ย/การกระจาย/Top 5 ใหม่ทุกครั้ง (เกณฑ์ ดีมาก ≥ 90% · มาตรฐาน 85–89% · ต้องปรับปรุง < 85%)

### แบบ F — ไฟล์ข้อมูลของเว็บ (แบบฟอร์ม)


1. กด **⤒ นำเข้าข้อมูล** → **ดาวน์โหลดไฟล์ข้อมูลปัจจุบัน**
2. เปิดใน Excel เติมแถวของเดือนใหม่ในแต่ละชีต (ดูแบบจากแถวเดือน 6)
3. ลากไฟล์กลับมาวางในหน้าเว็บ
4. เดือนที่อยู่ในไฟล์จะแทนที่เดือนเดิม เดือนอื่นคงไว้ตามเดิม (ค่าที่ไฟล์ใหม่ไม่มี เช่น Budget/CEM จะคงของเดิมไว้ ไม่ถูกล้าง)

ลบเดือน: กด × ที่ชื่อเดือนในหน้านำเข้า

## ชีตในไฟล์ข้อมูล

| ชีต | ข้อมูล | หมายเหตุ |
|---|---|---|
| `Monthly` | ยอดขาย / ปีก่อน / Budget / SSSG / MoM / จำนวนสาขา | **ต้องมี** 1 แถวต่อเดือน ชีตอื่นไม่บังคับ |
| `Delivery` | ยอดแต่ละ Platform เดือนก่อน vs เดือนนี้ (ล้านบาท) | แถว `สัดส่วน%` = สัดส่วน Delivery ต่อยอดขายรวม |
| `DeliveryDecline` | สาขาที่ Delivery ลดมากสุด (บาท) | กลุ่ม `รวม` หรือ `Line Man` |
| `Trans` | จำนวนบิล / เช็คเฉลี่ย / ลูกค้า แยกช่องทาง | แถว Trans, Ticket, Customer, Customer avg ใช้คอลัมน์ ค่าก่อน/ค่านี้; แถวช่องทางใช้ครบ 4 คอลัมน์ |
| `Branches` | สาขาที่ดี / น่าเป็นห่วง (Trans % / Ticket %) | กลุ่ม `ดี` หรือ `น่าเป็นห่วง` |
| `Audit` | CEM และ OSS | ประเภท `สรุป` (เฉลี่ยปีก่อน, เฉลี่ยปีนี้, จำนวนสาขา) / `กระจาย2025` / `กระจาย2026` (ดีเยี่ยม, ปานกลาง, ปรับปรุง) / `Top` (สาขา, คะแนนปีนี้, คะแนนปีก่อน) |
| `Notes` | ข้อความสรุปใต้แต่ละหัวข้อ | ส่วน `delivery` / `trans` / `branches` |

## หัวข้อในรายงาน

**หมวด 1 ยอดขาย** 1 KPI ภาพรวม · 2 ยอดขายรายเดือน (+แท็บกำไร) · 3 %SSSG · 4 อันดับยอดขายสาขา · 5 สุขภาพกลุ่มห้าง · 6 แนวโน้มรายโซน BZM · 7 รายสาขา ดี/น่าห่วง · 8 ทำได้ตามแผน · 9 เจาะรายสาขา · 10 Delivery · 11 สาขา Delivery ลดแรง · 12 Trans·Ticket·ลูกค้า

**หมวด 2 COL / COS** 1 ต้นทุนอาหาร (COS) และค่าแรง (COL) · 2 กำไรรายสาขา

**หมวด 3 P&L** ผังบัญชีเต็ม + ตารางสาขา x เดือน · **หมวด 4 CEM** · **หมวด 5 OSS**

หัวข้อ 8–12 จะขึ้นเมื่อมีข้อมูลจากไฟล์ที่เกี่ยวข้องเท่านั้น (แบบฟอร์มส่งยอดขาย / P&L / CEM / OSS)

เดือนใช้ตัวเลข 1–12 ทุกชีต หัวข้อที่ไม่มีข้อมูลจะขึ้น "ยังไม่มีข้อมูล" ในหน้าเว็บ

## ดึงรายงาน

กด **⤓ ดึงรายงาน**

- **พิมพ์ / บันทึก PDF** — A4 แนวนอน หน้าละ 1 หัวข้อ
- **Excel รายงานเดือนนี้** — ตารางสรุปแยกชีตตามหัวข้อ
- **Excel ไฟล์ข้อมูลทุกเดือน** — ไฟล์เดียวกับแบบฟอร์มนำเข้า ใช้สำรองข้อมูลได้

## ที่เก็บข้อมูล

- **เวอร์ชันลิงก์ claude.ai** — เก็บกลาง ทุกคนที่เปิดลิงก์เห็นข้อมูลเดียวกัน เปิดได้เฉพาะคนในองค์กรที่ล็อกอิน
- **เปิดไฟล์ .html ตรงๆ** — เก็บในเบราว์เซอร์เครื่องนั้น ไม่แชร์ ถ้าล้างข้อมูลเบราว์เซอร์ให้นำเข้าไฟล์ Excel ใหม่

ครั้งแรกต้องมีอินเทอร์เน็ตเพื่อโหลดฟอนต์ Sarabun และตัวอ่าน Excel (SheetJS จาก cdnjs)

## แก้ค่าเริ่มต้นในโค้ด

ตัวเลขตั้งต้นอยู่ในบล็อก `DEFAULT_MONTHLY` และ `DEFAULT_DETAIL` ต้นสคริปต์ในไฟล์ HTML — ปัจจุบันฝังข้อมูลจริง ม.ค.–ส.ค. 2026 ไว้แล้ว (สร้างจากไฟล์ Daily Sale + แบบฟอร์มส่งยอดขาย + P&L + CEM + OSS) เปิดลิงก์แล้วเห็นครบทันทีโดยไม่ต้องนำเข้า ส่วนการนำเข้าไฟล์ใช้สำหรับอัปเดตเดือนใหม่ ธีมสีอยู่ใน `:root` — โทนขาว-ส้ม (`--orange #F66B21`, `--orange-ink #D2510F` สำหรับตัวอักษรบนพื้นขาว, `--orange-2` พื้นอ่อน, `--ink/--mute/--line/--bg/--card` โทนกลาง) แก้ที่นี่ที่เดียวเปลี่ยนทั้งเว็บ
